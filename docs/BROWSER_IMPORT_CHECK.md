# Проверка загрузки Zara браузером — 12.11.2026

Результат: загрузка карточек и чтение цены с alex-server технически возможны. Проверка изолированная, рабочий бот не менялся.

## Условия

Официальный Playwright Python 1.64.1, Chromium в отдельном временном Docker-контейнере. Один браузер за раз, ограничение 1 CPU / 1536 MiB RAM / 256 MiB shared memory. Без новых портов, без подключения к базе заказов и без учетной записи магазина. Браузер с окном запущен через виртуальный экран Xvfb; работа возможна без монитора на сервере. Прокси, подмена браузерных отпечатков, решения CAPTCHA не использовались.

## Извлечение цены

В сохраненной карточке основная цена находится внутри `.product-detail-info__price [data-qa-id="price-container-current"] data[data-currency="EUR"]`; значение `data.value` равно `35.95`, видимый дочерний `.money-amount__main` показывает `35.95 EUR`. При внедрении проверять единственность, валюту EUR, положительное десятичное значение и соответствие карточке; не брать первый `.money-amount__main` со всей страницы из-за рекомендаций и старых цен.

Существующий JSON-LD-парсер product_metadata на полученном HTML не определил товар и цену — одного изменения способа загрузки недостаточно, нужен дополнительный извлекатель основной цены из DOM.

## Ограничения и следующий этап

Подтверждено успешное получение двух карточек в двух коротких сессиях. Долговременная стабильность, скидки, варианты с различными ценами, недоступные товары и H&M данным тестом не проверены. Для внедрения нужен отдельный браузерный сервис с последовательной очередью запросов, таймаутом, ограничением ресурсов и ручным вводом при блокировке/неоднозначности. Стилисту показывать найденную цену для подтверждения. В этой задаче внедрение не выполнялось.

Артефакты: `work/browser-probe/results-initial.json`, `results-repeat.json`, HTML и скриншоты двух карточек. Временный контейнер завершился автоматически; рабочие api/bot/db продолжили работать. Порты, Tailscale и конфигурация рабочих служб не менялись.
