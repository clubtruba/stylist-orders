## Необходимые изменения
1. Разделить Telegram-аккаунт стилиста и получателя; один стилист формирует заказы разных клиентов.
2. Ввести заказ как группу товаров со своим номером, адресом, черновиком и стадией оформления. В старом боте оформление начинается с отдельной ссылки и профиля текущего пользователя.
3. Добавить несколько сохраняемых заказов и выбор активного заказа.
4. Добавить неизменяемые расчеты заказа с курсом и надбавками.
5. Привязать платежные вложения к заказу и расчету: старая PaymentEvidence требует item_id.
6. Ограничить вход разрешенными ID; старый start регистрирует клиента.
7. Добавить приглашение получателя для уведомлений без права формирования заказов.
8. Сохранить прежние рабочие статусы товаров и создание посылок в новой админской части.
