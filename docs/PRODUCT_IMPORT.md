Прямая загрузка всех четырех страниц системным HTTPS-клиентом получила HTTP 403 из среды разработки. По веб-просмотру читаются названия двух H&M, но актуальная цена не подтверждена. Это не означает, что загрузка с сервера пользователя даст тот же результат: требуется повторная проверка после подготовки окружения.

Добавлен модуль product_import: проверка испанских товарных URL Zara/H&M, попытка HTTP-загрузки без следования перенаправлениям, ограничение размера HTML, извлечение однозначного EUR Offer из Product JSON-LD. При блокировке, неоднозначности, другой валюте или отсутствии цены возвращается причина ручного ввода. Это начальная реализация, не подтвержденная работающая интеграция с живыми магазинами. Размер, цвет и количество вводятся вручную.

Следующий этап: установить зависимости, проверить HTTP-сценарии на подмененных ответах, связать импорт с новым оформлением заказа, повторить проверку с сервера. Цена сохраняется с источником и временем получения; отсутствие цены не должно превращаться в нулевую стоимость или расчет к оплате.

Повторная проверка 11.11.2026 непосредственно с alex-server также получила HTTP 403 для всех четырех ссылок. Автоматическое чтение цены не считается подтвержденным; ручной ввод доступен в боте и Mini App.


## Браузерная проверка 12.11.2026
Получение цены Zara подтвердилось в отдельном тесте Chromium с окном через Xvfb: главная → карточка. Два товара вернули HTTP 200 и цены 35.95 EUR / 19.95 EUR, новая чистая сессия повторила успех для первой карточки. Фоновый Chromium продолжал получать403. В бот способ пока не подключен; требуется извлечение цены основного товара из DOM и отдельный ограниченный браузерный сервис. Подробности: BROWSER_IMPORT_CHECK.md. Это проверка осуществимости, не подтверждение долговременной стабильности.


## Внедрение браузерного импорта
Добавлена внутренняя product-browser служба. Для Zara бот обращается к ней, она открывает испанскую главную страницу и затем товар в Chromium с окном. Читается единственная текущая EUR-цена в блоке основного товара (без рекомендаций и старой цены), проверяется идентификатор карточки. Бот показывает найденную цену для подтверждения; ошибка или таймаут ведут к явному запросу ручного ввода. Подтвержденная без изменения цена получает источникzara_browser; исправленная/ручная — manual. Размер/цвет/количество вручную. H&M пока использует HTTP/JSON-LD, браузерная поддержка H&M не заявлена.

## Подтверждение цены товара
Если цена найдена, нажмите «Да» либо «Изменить цену». Затем отправьте размер; цвет; количество, например `M; черный; 2`. Количество можно опустить (1 штука); если цвет выбирать не нужно, достаточно размера `M`. Несколько штук без выбора цвета: `M; -; 2`. Можно разделять параметры запятыми. Если цена не найдена, бот сначала запрашивает только цену в евро, затем параметры.
