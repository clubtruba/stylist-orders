# Получение товаров: проверка 11.11.2026

Присланные примеры:
- https://www2.hm.com/es_es/productpage.1352121001.html
- https://www2.hm.com/es_es/productpage.1357440002.html
- https://www.zara.com/es/en/sarouel-trousers-with-ties-zw-collection-p03036069.html?v1=610543659&v2=2420795
- https://www.zara.com/es/en/basic-plush-trousers-p03199635.html?v1=594401162&v2=2419265

Прямая загрузка всех четырех страниц системным HTTPS-клиентом получила HTTP 403 из среды разработки. По веб-просмотру читаются названия двух H&M, но актуальная цена не подтверждена. Это не означает, что загрузка с сервера пользователя даст тот же результат: требуется повторная проверка после подготовки окружения.

Добавлен модуль product_import: проверка испанских товарных URL Zara/H&M, попытка HTTP-загрузки без следования перенаправлениям, ограничение размера HTML, извлечение однозначного EUR Offer из Product JSON-LD. При блокировке, неоднозначности, другой валюте или отсутствии цены возвращается причина ручного ввода. Это начальная реализация, не подтвержденная работающая интеграция с живыми магазинами. Размер, цвет и количество вводятся вручную.

Следующий этап: установить зависимости, проверить HTTP-сценарии на подмененных ответах, связать импорт с новым оформлением заказа, повторить проверку с сервера. Цена сохраняется с источником и временем получения; отсутствие цены не должно превращаться в нулевую стоимость или расчет к оплате.

Повторная проверка 11.11.2026 непосредственно с alex-server также получила HTTP 403 для всех четырех ссылок. Автоматическое чтение цены не считается подтвержденным; ручной ввод доступен в боте и Mini App.
