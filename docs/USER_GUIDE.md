# Оформление заказа в боте

1. Откройте @spain_oders_bot и нажмите «Старт» → «Новый заказ».
2. Выберите сохраненного получателя либо «Новый получатель».
3. Бот последовательно спросит имя и фамилию латиницей, телефон, Telegram username, индекс, регион, город и адрес. Отправляйте один ответ на каждый вопрос. Telegram username можно пропустить кнопкой «Пропустить». Кнопка «Назад» возвращает к предыдущему полю, «Отменить ввод» закрывает форму. Для продолжения незавершенной формы используйте /start.
4. Пришлите ссылки Zara или H&M. Подтвердите найденную цену кнопкой «Да» (либо введите цену отдельно, если она не найдена). Затем выберите цвет, размер и количество кнопками. Если данные с сайта не получены — введите цвет и размер по одному сообщению.
5. «Продолжить позже» сохраняет заказ; вернуться можно через «Мои заказы».
6. «Расчет» выставляет оплату с возможностью последующего дополнения. «Завершить заказ» закрывает формирование после оплаты.
7. Под расчетом нажмите «Прикрепить скриншот» и отправьте изображение. Фактический перевод для теста не нужен; скриншот считается подтверждением.

Стоимость: товары +20%; рубли — по курсу ЦБ с надбавкой5%. Выставленная сумма фиксируется. При дополнении оплачиваются только новые позиции. Доставка учитывается отдельно после отправки. Статусы, расчеты, скриншоты и трек доступны в Mini App через кнопку «Заказы»; изменения приходят в бот. Отмены и возвраты оформляет администратор.


Вход в приложение: отправьте /start, затем нажмите «Открыть заказы» под новым сообщением бота. Кнопка «Открыть приложение» на клавиатуре присылает такую же кнопку входа. Старые кнопки открытия под клавиатурой могут не передавать данные Telegram — закройте старое окно и откройте приложение заново.

Администратор видит заказы всех операторов через «Мои заказы» или /orders; управление товарами, оплатами и отправлениями — в приложении. Стилист видит только свои заказы.

Имя и фамилия — только английские буквы A–Z, как в паспорте. Регион, город, улица и дополнение к адресу — английскими буквами; можно использовать цифры и знаки . , / ' # ( ) -. Например: Moscow Oblast; Moscow; Tverskaya St., 10, Apt. 5. Русские и смешанные буквы не принимаются. Telegram username остается необязательным.


После ссылки Zara бот проверяет цену через браузер (обычно несколько секунд, при проблемах до минуты). Если цена найдена, подтвердите ее кнопкой «Да» либо нажмите «Изменить цену». Если магазин не ответил, заблокировал загрузку или цена неоднозначна, бот попросит ввести только цену в евро. Затем укажите параметры товара. Ошибка автоматического получения не закрывает заказ. Для H&M автоматическая попытка остается прежней, при недоступности — ручной ввод.


## Выбор товара кнопками

После подтверждения цены:

1. Выберите цвет. Если цвет один, бот выберет его автоматически и покажет на следующем шаге. Цвета подписаны так же, как на сайте магазина.
2. Выберите размер: XS/S/M или цифровые размеры — из карточки выбранного цвета. Кнопки показывают только размеры с отметкой «в наличии» на момент загрузки; это не резервирование товара.
3. Выберите количество: 1, 2, 3 или «Другое количество» (от 1 до 100). После этого товар сохраняется, бот показывает итог и просит следующую ссылку.

«Ввести вручную» позволяет указать свой цвет или размер. «Назад» возвращает к предыдущему шагу. Если цвет не нужно указывать, нажмите «Без выбора цвета».

Если выбранный размер/цвет дороже или дешевле подтвержденной цены, бот запросит подтверждение новой цены до сохранения. Цена, которую вы исправили вручную, автоматически не заменяется.

При недоступной цене сначала введите только цену в евро. Без данных о вариантах бот попросит цвет и размер вручную, затем покажет кнопки количества. Для H&M пока используется этот ручной выбор; автоматические варианты реализованы для Zara.

Ранее начатые формы со старым форматом продолжают работать. Чтобы перейти на новый сценарий, сохраните заказ кнопкой «Продолжить позже» и откройте его снова через «Мои заказы».
