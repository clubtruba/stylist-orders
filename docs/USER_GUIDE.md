# Оформление заказа в боте

1. Откройте @spain_oders_bot и нажмите «Старт» → «Новый заказ».
2. Выберите сохраненного получателя либо «Новый получатель».
3. Бот последовательно спросит имя и фамилию латиницей, телефон, Telegram username, индекс, регион, город и адрес. Отправляйте один ответ на каждый вопрос. Telegram username можно пропустить кнопкой «Пропустить». Кнопка «Назад» возвращает к предыдущему полю, «Отменить ввод» закрывает форму. Для продолжения незавершенной формы используйте /start.
4. Пришлите ссылки Zara или H&M. Для каждого товара введите параметры в формате: `29,99; M; черный; 1` — цена EUR, размер, цвет, количество.
5. «Продолжить позже» сохраняет заказ; вернуться можно через «Мои заказы».
6. «Расчет» выставляет оплату с возможностью последующего дополнения. «Завершить заказ» закрывает формирование после оплаты.
7. Под расчетом нажмите «Прикрепить скриншот» и отправьте изображение. Фактический перевод для теста не нужен; скриншот считается подтверждением.

Стоимость: товары +20%; рубли — по курсу ЦБ с надбавкой5%. Выставленная сумма фиксируется. При дополнении оплачиваются только новые позиции. Доставка учитывается отдельно после отправки. Статусы, расчеты, скриншоты и трек доступны в Mini App через кнопку «Заказы»; изменения приходят в бот. Отмены и возвраты оформляет администратор.


Вход в приложение: отправьте /start, затем нажмите «Открыть заказы» под новым сообщением бота. Кнопка «Открыть приложение» на клавиатуре присылает такую же кнопку входа. Старые кнопки открытия под клавиатурой могут не передавать данные Telegram — закройте старое окно и откройте приложение заново.

Администратор видит заказы всех операторов через «Мои заказы» или /orders; управление товарами, оплатами и отправлениями — в приложении. Стилист видит только свои заказы.

Имя и фамилия — только английские буквы A–Z, как в паспорте. Регион, город, улица и дополнение к адресу — английскими буквами; можно использовать цифры и знаки . , / ' # ( ) -. Например: Moscow Oblast; Moscow; Tverskaya St., 10, Apt. 5. Русские и смешанные буквы не принимаются. Telegram username остается необязательным.


После ссылки Zara бот проверяет цену через браузер (обычно несколько секунд, при проблемах до минуты). Если цена найдена, сообщение содержит цену и пример: «35,95; M; черный; 1». Подтвердите ее этим сообщением со своими размером, цветом и количеством либо исправьте цену. Если магазин не ответил, заблокировал загрузку или цена неоднозначна, бот попросит ввести цену вручную в том же формате. Ошибка автоматического получения не закрывает заказ. Для H&M автоматическая попытка остается прежней, при недоступности — ручной ввод.
