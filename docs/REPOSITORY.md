# Репозиторий и публикация

Новый самостоятельный репозиторий: https://github.com/clubtruba/stylist-orders.

Репозиторий предыдущего бота clubtruba/telegram-orders остается без изменений.

## Первоначальная загрузка

Подготовленный ZIP содержит содержимое корня проекта: README.md, backend, bot, mini-app и docs. Распакуйте ZIP, откройте новый репозиторий на GitHub, выберите **Add file → Upload files** и загрузите содержимое распакованной папки. README.md должен находиться в корне репозитория. Архив целиком загружать вместо файлов не нужно.

Локальный `.env`, временные HTML, кэши и зависимости в ZIP не включены. `.gitignore` есть в архиве, но браузерный выбор файлов может не показывать скрытые файлы; при дальнейшей работе через Git он должен быть добавлен в корень.
