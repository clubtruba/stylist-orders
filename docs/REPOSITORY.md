# Репозиторий и публикация

Новый самостоятельный репозиторий: https://github.com/clubtruba/stylist-orders.

Репозиторий предыдущего бота clubtruba/telegram-orders остается без изменений.

## Первоначальная загрузка

Подготовленный ZIP содержит содержимое корня проекта: README.md, backend, bot, mini-app и docs. Распакуйте ZIP, откройте новый репозиторий на GitHub, выберите **Add file → Upload files** и загрузите содержимое распакованной папки. README.md должен находиться в корне репозитория. Архив целиком загружать вместо файлов не нужно.

Локальный `.env`, временные HTML, кэши и зависимости в ZIP не включены. `.gitignore` есть в архиве, но браузерный выбор файлов может не показывать скрытые файлы; при дальнейшей работе через Git он должен быть добавлен в корень.

## GitHub Pages

Планируемый домен: https://style.papamio.es.

DNS CNAME проверен: style.papamio.es → clubtruba.github.io. На последней проверке HTTPS-сертификат не соответствовал поддомену. Настройка DNS сама по себе не публикует приложение.

Публикация ожидает запуска отдельного нового API. Добавлен ручной workflow Deploy Stylist Mini App, который проверяет новый API перед публикацией. До этого нет необходимости менять настройки старого Pages или вручную загружать исходники React как готовый сайт.

После подготовки сборки в **новом** репозитории будут настроены Pages → GitHub Actions, новый публичный HTTPS API, custom domain style.papamio.es и Enforce HTTPS после выпуска сертификата. Точный URL API будет установлен после проверки отдельного серверного развертывания.

## Сервер

По документам старого проекта новая соседняя папка планируется как `/mnt/ai/repos/stylist-orders`. Доступ к серверу подтвержден. Новый проект должен иметь отдельные сервисы, базу, тома, резервные копии и каталог платежных вложений.
