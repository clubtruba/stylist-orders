3. API, права доступа и сохраненные получатели — реализованы, тесты проходят.
4. Бот: несколько заказов, очередь ссылок, расчет и скриншоты — реализовано; живые Telegram-проверки после запуска.

8. Проверки — 61 тест проходит, образы API и бота собираются; CI будет проверен в GitHub.
