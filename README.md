# Stylist Orders — заказы из Испании

Telegram-бот, сервер и мини-приложение для оформления стилистом заказов в магазинах Испании с доставкой получателям в России.

Репозиторий: https://github.com/clubtruba/stylist-orders

Планируемый адрес Mini App: https://style.papamio.es

## Сценарий

Стилист выбирает сохраненного получателя или создает нового, добавляет товары ссылками, указывает размер, цвет и количество. Заказ можно отложить, получить промежуточный расчет и дополнить либо завершить формирование. Скриншот подтверждает оплату выставленного расчета. Администратор покупает товары, меняет статусы, оформляет отправку, отмены и возвраты.

Стоимость товаров увеличивается на 20%. Сумма в рублях рассчитывается по курсу ЦБ РФ с надбавкой 5%. Выставленная сумма не меняется при более позднем получении скриншота. Доставка учитывается отдельно после отправки.

## Состояние проекта

Реализована первая версия сценария стилиста: получатели, несколько заказов и очереди ссылок, расчеты и доплаты, скриншоты, отмены и возвраты. Сохранены прежние экраны покупок и склада. Локально проходят 61 тест с PostgreSQL и сборка Mini App; мобильные экраны проверены на вымышленных данных.

Боевой запуск и проверка реальными Telegram-аккаунтами еще не выполнены. Подробности — в [состоянии реализации](docs/STATUS.md). Zara и H&M отвечают HTTP 403 на проверенные серверные запросы, поэтому сейчас предусмотрен ручной ввод цены.

## Структура

- `backend/` — FastAPI, SQLAlchemy, PostgreSQL, миграции и бизнес-правила.
- `bot/` — обработчики Telegram на aiogram.
- `mini-app/` — React, TypeScript, Vite.
- `docs/` — требования, архитектура, план и текущее состояние.

## Проверка новых независимых модулей

Из каталога `backend`, Python 3.12:

```sh
python3 -m unittest discover -s tests -p test_pricing.py -v
python3 -m unittest discover -s tests -p test_quote_payment.py -v
python3 -m unittest discover -s tests -p test_product_import.py -v
```

Полный набор тестов требует отдельного PostgreSQL: примените миграции и запустите pytest из backend. CI поднимает собственную тестовую базу автоматически. Код публикации Pages запускается только вручную и проверяет доступность нового API перед сборкой.
